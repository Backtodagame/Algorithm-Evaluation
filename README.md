# Algorithm-Evaluation
We evaluate how well an algorithm performs.
- BT1 contains Looping and Recursion method when they are applied to solve Fibonacci problem ( How many elements that these two methods can process and their running time, respectively). Source code is written in both Python and C++ languages.
- BT2 contains Insertion sort and Heap sort, they are applied to sort a list with N-element. Source code is written in Python language.
